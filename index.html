การเชื่อมต่อ MQTT

ESP32 ใช้ MQTT TCP port 1883 ส่วน Dashboard ในเบราว์เซอร์ใช้ Secure WebSocket (WSS) port 8884 และ path /mqtt โดยเชื่อมต่อ Broker เดียวกัน

หากเปลี่ยนชื่อ Topic ในโค้ด Arduino ให้เปลี่ยน Topic ใน Dashboard ให้ตรงกันทุกตัวอักษร
